# Agent guidance — single-owner default (2026-11-23)

Read this repository's README, current issues and task-specific instructions first. Follow the canonical [autonomous-workflow Skill](https://github.com/ryok247/agent-lab/blob/main/.agents/skills/autonomous-workflow/SKILL.md) if available; the link alone does not install it. Keep existing project-specific safety, licensing, expense and Git instructions authoritative.

- Assume the **repository owner is the sole available human**. Prefer work agents can finish autonomously; do not plan around multiple reviewers, testers, interviewees or annotators without an explicit justified need and approval.
- Where useful, design a minimal owner-operated N=1 verification with exact steps and observable success criteria; it is **not** independent gold-standard evaluation, representative customer evidence or a substitute for third-party consent or legally/ethically required independent oversight.
- Prepare all automated work first and ask the owner only at one meaningful bounded checkpoint, ideally 10–30 minutes, with precise action and evidence requested. Never infer approval from silence; no unauthorized contact, deployment, payment, data sharing or destructive operations.
- Audit human-blocked work against existing issues before opening a new one. Create/update an actionable resume ticket only when a real decision could change, containing past evidence, blocker, smallest owner action, autonomous next step and HOLD/STOP condition. Avoid duplicate or speculative tickets.
- Report executed checks separately from unverified assertions; commit and push only under the repository's existing permissions and workflow.
